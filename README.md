# Curso de HTML5 e CSS3

Repositório criado para reunir os exercícios desenvolvidos durante meus estudos de HTML5 e CSS3 por meio dos cursos do Curso em Vídeo.

## 🎯 Objetivos

- Aprender os fundamentos do desenvolvimento web.
- Compreender a estruturação de páginas com HTML5.
- Praticar a estilização de páginas com CSS3.
- Desenvolver páginas web aplicando os conceitos aprendidos ao longo do curso.

## 📖 Conteúdos estudados

- Estrutura básica de documentos HTML.
- Elementos, links, imagens e listas.
- Estilização com CSS.
- Cores, fontes, seletores e layouts.
- Desenvolvimento de páginas web responsivas, conforme os conteúdos estudados.

## 📋 Organização

Os arquivos estão organizados de acordo com as aulas e exercícios realizados durante o curso.

## 💻 Tecnologias

- HTML5
- CSS3
